# _rules — the non-negotiables, one rule per file

One job: hold the rules that must not be re-litigated, each in its own file, each
naming the test that guards it.

These were a single 255-line section of `CLAUDE.md`. They moved out because the
entry file is a catalog and a catalog holds no books: at 675 lines it was loading
~11k tokens into every session to answer "where am I". Splitting them also fixed a
filing bug the flat list could not surface — two rules
([a-gate-that-cannot-run-fails-closed](a-gate-that-cannot-run-fails-closed.md) and
[a-missing-watermark-stops-the-build](a-missing-watermark-stops-the-build.md)) had
drifted 135 lines out of the section, into the middle of the runbook.

## Inputs

- Reference (every run): the rule file for the area you are changing — see the table
- Reference (every run): `../_reference/config-schema.md`, `../_reference/layout.md`
- Working (when changing code): the test named in that rule's `guarded_by`

## Process

1. Before changing `make_tour.py`, `tour.py`, `publish.py`, `status.py` or
   `scraper/`, read the rules whose `area` matches what you are touching. Do not
   read all 40 — that is the load this split exists to prevent.
2. A rule is not advice. If a change contradicts one, say so and stop; the rule
   states why it exists, and most of them record a failure that already shipped.
3. Adding a rule: one file, frontmatter as below, then `python3 _rules/reindex.py`.
4. Retiring a rule: move the file to `../_archive/` with a line saying what
   replaced it. Never delete — the reasoning is the value.

## Frontmatter

```yaml
name: kebab-slug                  # must match the filename
area: interface|photos|scrape|naming|build|card|delivery|publishing|outreach|pii|docs
type: non-negotiable
guarded_by:                       # [] when nothing tests it -- that is a finding
  - tests/test_x.py
source: CLAUDE.md@717ce32 L214-225   # where it lived before the split
```

## Outputs

- `CONTEXT.md`'s table below, regenerated by `python3 _rules/reindex.py`.
  **Never hand-edit it** — `--check` exits 1 when it is stale.

## Human check

Run `python3 _rules/reindex.py --check`. Then read the *Guarded by* column: a rule
reading *prose only* is a rule nothing enforces. That is the list worth shrinking.
